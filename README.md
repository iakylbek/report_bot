# Складской бот

Бот для учёта товаров на складе. Через Telegram можно добавить сотрудников,
комплектующие и продукты, внести поступление или отгрузку, посмотреть остатки
и скачать данные в Excel. Данные хранятся в PostgreSQL.

## Запуск

Нужны Python, PostgreSQL и токен бота. Создайте базу и пользователя PostgreSQL,
затем заполните `.env` по примеру `.env.example`:

```env
BOT_TOKEN=токен_бота
ADMIN_ID=ваш_Telegram_ID
DATABASE_URL=postgresql+asyncpg://warehouse_user:password@localhost:5432/warehouse
```

`ADMIN_ID` — первый сотрудник, которому будет доступен бот. Остальных можно
добавить уже через Telegram. Работает бот только в личном чате и только для
сотрудников, добавленных в базу.

Из корня проекта выполните:

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

При запуске создаются отсутствующие таблицы. Уже существующие таблицы команда
не меняет.

## Как пользоваться

Отправьте боту `/start`. В меню будут «Остатки», «Поступления», «Отгрузки»,
«Внести данные» и «Скачать в Excel».

В разделе «Внести данные» сначала можно добавить сотрудника по Telegram ID.
При добавлении товара выбирается тип:

- Комплектующее: артикул, название, цена, ответственный из списка сотрудников
  и комментарий.
- Продукт: артикул, название и комплектующие с количеством каждого.

Новый товар создаётся с нулевым остатком. Состав продукта хранится отдельно и
сам по себе не списывает комплектующие.

Чтобы записать движение, выберите «Внести поступления/отгрузку», товар,
тип операции, количество и комментарий. Поступление увеличивает остаток,
отгрузка уменьшает. Ответственный при операции не вводится. Кнопка «⬅️ Назад»
или команда `/start` отменяет незавершённый ввод.

«Остатки» показывает сохранённое количество всех товаров. В поступлениях и
отгрузках можно выбрать все товары или один конкретный, затем период 7 или
30 дней. Записи идут от новых к старым, по 10 на странице. Время показывается
по Москве.

«Скачать в Excel» отправляет файл с четырьмя листами: «Товары», «Сотрудники»,
«Движения» и «Продукты». На последнем листе указан состав готовых продуктов.

## Код и тесты

`main.py` запускает бота. В `app/handlers` находятся диалоги Telegram,
в `app/services` — проверка данных и логика, в `app/repositories` — запросы
к базе через SQLAlchemy. Модели таблиц лежат в `app/models.py`.

Запуск тестов:

```bash
python -B -m unittest discover -s app/tests -v
```
